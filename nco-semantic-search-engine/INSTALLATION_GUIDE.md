## System Requirements

### Minimum Hardware
- **CPU**: Dual-core processor (4+ cores recommended)
- **RAM**: 8GB (16GB recommended for optimal performance)
- **Disk Space**: 10GB+ for models and database
- **Network**: Internet connection (for initial model downloads)

### Required Software
- **Python**: 3.10 or higher
- **PostgreSQL**: 12 or higher
- **Git**: Latest version (for cloning the repository)

### Supported Operating Systems
- Windows 10/11 (64-bit)
- Ubuntu 20.04+ / Linux (64-bit)
- macOS 11+ (Intel/Apple Silicon)

## Installation on Windows

### Step 1: Install Prerequisites

#### 1.1 Install Python 3.10+
1. Download from [python.org](https://www.python.org/downloads/)
2. Run the installer
3. **Important**: Check "Add Python to PATH" during installation
4. Verify installation:
   ```cmd
   python --version
   pip --version
   ```

#### 1.2 Install PostgreSQL
1. Download from [postgresql.org](https://www.postgresql.org/download/windows/)
2. Run the installer
3. Set a password for the `postgres` user (remember this)
4. Keep the default port `5432`
5. Accept the default data directory
6. Install pgAdmin (recommended for database management)
7. Verify installation:
   ```cmd
   psql --version
   ```

#### 1.3 Install Git
1. Download from [git-scm.com](https://git-scm.com/download/win)
2. Run the installer with default settings
3. Verify installation:
   ```cmd
   git --version
   ```

### Step 2: Clone the Repository

```cmd
git clone https://github.com/2004Muhilan/nco-semantic-search-engine.git
cd nco-semantic-search-engine
git checkout Removed-NLLB-220
```

### Step 3: Create Virtual Environment

```cmd
python -m venv venv
venv\Scripts\activate
```

Your prompt should show `(venv)` prefix.

### Step 4: Install Python Dependencies

```cmd
pip install --upgrade pip
pip install -r requirements.txt
```

For IndicTrans2 transliteration support, additionally run:

```cmd
pip install git+https://github.com/facebookresearch/fairseq.git@main
pip install "hydra-core==1.0.7" --no-deps
```

### Step 5: Create PostgreSQL Database

#### 5.1 Using pgAdmin (Recommended)
1. Open pgAdmin
2. Right-click "Databases" → "Create" → "Database"
3. Name: `statathon_nco`
4. Owner: `postgres`
5. Click "Save"

#### 5.2 Using Command Line
```cmd
psql -U postgres -c "CREATE DATABASE statathon_nco OWNER postgres;"
```

Enable pgvector extension:
```cmd
psql -U postgres -d statathon_nco -c "CREATE EXTENSION IF NOT EXISTS vector;"
```

### Step 6: Create Environment Configuration

Create a `.env` file in the project root:

```env
DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@localhost:5432/statathon_nco
ADMIN_PASSWORD=your_secure_admin_password
SECRET_KEY=your_random_secret_key
HF_HUB_OFFLINE=1
INDICTRANS2_CT2_DIR=models/indictrans2-ct2
```

Replace:
- `YOUR_PASSWORD` with your PostgreSQL password
- `your_secure_admin_password` with a strong password for admin login
- `your_random_secret_key` with any random string (e.g., generated by `python -c "import secrets; print(secrets.token_hex(32))"`)

### Step 7: Download Models

```cmd
python scripts/download_indictrans2_model.py
```

This downloads the IndicTrans2 CT2 model (~1.5GB) to `models/indictrans2-ct2/`. Ensure you have a stable internet connection and sufficient disk space.

### Step 8: Initialize Database

```cmd
python scripts/migrate_to_postgres.py
```

This creates tables and imports occupation data.

### Step 9: Run the Application

```cmd
python app.py
```

You should see:
```
 * Running on http://127.0.0.1:5000
Press CTRL+C to quit
```

Open your browser:
- **Public UI**: http://127.0.0.1:5000/
- **Admin Dashboard**: http://127.0.0.1:5000/admin

### Step 10: Stop the Application

Press `CTRL+C` in the terminal.

## Installation on Linux/Ubuntu

### Step 1: Install Prerequisites

#### 1.1 Update System Packages
```bash
sudo apt update
sudo apt upgrade -y
```

#### 1.2 Install Python 3.10+
```bash
sudo apt install -y python3.10 python3.10-venv python3-pip
```

Verify:
```bash
python3 --version
pip3 --version
```

#### 1.3 Install PostgreSQL
```bash
sudo apt install -y postgresql postgresql-contrib postgresql-client
```

Verify:
```bash
psql --version
```

Start PostgreSQL service:
```bash
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

#### 1.4 Install Git
```bash
sudo apt install -y git
```

Verify:
```bash
git --version
```

#### 1.5 Install Build Tools (Required for some Python packages)
```bash
sudo apt install -y build-essential libssl-dev libffi-dev python3-dev
```

### Step 2: Clone the Repository

```bash
git clone https://github.com/2004Muhilan/nco-semantic-search-engine.git
cd nco-semantic-search-engine
git checkout Removed-NLLB-220
```

### Step 3: Create Virtual Environment

```bash
python3 -m venv venv
source venv/bin/activate
```

Your prompt should show `(venv)` prefix.

### Step 4: Install Python Dependencies

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

For IndicTrans2 transliteration support, additionally run:

```bash
pip install git+https://github.com/facebookresearch/fairseq.git@main
pip install "hydra-core==1.0.7" --no-deps
```

### Step 5: Create PostgreSQL Database

#### 5.1 Create Database and User
```bash
sudo -u postgres psql << EOF
CREATE USER nco_user WITH PASSWORD 'your_secure_password';
CREATE DATABASE statathon_nco OWNER nco_user;
\c statathon_nco
CREATE EXTENSION IF NOT EXISTS vector;
GRANT ALL PRIVILEGES ON DATABASE statathon_nco TO nco_user;
EOF
```

Replace `your_secure_password` with a strong password.

#### 5.2 Verify Connection
```bash
psql -U nco_user -d statathon_nco -c "SELECT version();"
```

You'll be prompted for the password you just set.

### Step 6: Create Environment Configuration

Create a `.env` file in the project root:

```bash
cat > .env << 'EOF'
DATABASE_URL=postgresql://nco_user:your_secure_password@localhost:5432/statathon_nco
ADMIN_PASSWORD=your_secure_admin_password
SECRET_KEY=your_random_secret_key
HF_HUB_OFFLINE=1
INDICTRANS2_CT2_DIR=models/indictrans2-ct2
EOF
```

Replace:
- `your_secure_password` with the PostgreSQL password from Step 5.1
- `your_secure_admin_password` with a strong admin password
- `your_random_secret_key` with any random string

### Step 7: Download Models

```bash
python scripts/download_indictrans2_model.py
```

This downloads the IndicTrans2 CT2 model (~1.5GB) to `models/indictrans2-ct2/`. Ensure you have a stable internet connection and sufficient disk space.

### Step 8: Initialize Database

```bash
python scripts/migrate_to_postgres.py
```

This creates tables and imports occupation data.

### Step 9: Run the Application

```bash
python app.py
```

You should see:
```
 * Running on http://127.0.0.1:5000
Press CTRL+C to quit
```

Open your browser:
- **Public UI**: http://127.0.0.1:5000/
- **Admin Dashboard**: http://127.0.0.1:5000/admin

### Step 10: (Optional) Run as a Systemd Service

Create `/etc/systemd/system/nco-search.service`:

```bash
sudo tee /etc/systemd/system/nco-search.service > /dev/null << EOF
[Unit]
Description=NCO Semantic Search Engine
After=network.target postgresql.service

[Service]
Type=simple
User=your_username
WorkingDirectory=/home/your_username/nco-semantic-search-engine
Environment="PATH=/home/your_username/nco-semantic-search-engine/venv/bin"
ExecStart=/home/your_username/nco-semantic-search-engine/venv/bin/python app.py
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF
```

Replace `your_username` with your actual username.

Enable and start the service:
```bash
sudo systemctl daemon-reload
sudo systemctl enable nco-search
sudo systemctl start nco-search
sudo systemctl status nco-search
```

View logs:
```bash
sudo journalctl -u nco-search -f
```

## Configuration

### Environment Variables

Create or edit `.env` file in the project root:

```env
# PostgreSQL Database Connection
DATABASE_URL=postgresql://user:password@localhost:5432/dbname

# Admin Panel
ADMIN_PASSWORD=your_secure_admin_password
SECRET_KEY=your_random_secret_key

# Offline Mode (model weights pre-downloaded)
HF_HUB_OFFLINE=1

# IndicTrans2 Model Directory
INDICTRANS2_CT2_DIR=models/indictrans2-ct2
```

### Database Connection String Format

```
postgresql://[user]:[password]@[host]:[port]/[database]
```

Examples:
- **Local with password**: `postgresql://postgres:mypass@localhost:5432/statathon_nco`
- **Default postgres user**: `postgresql://postgres:password@localhost:5432/statathon_nco`
- **With SSL**: `postgresql://user:password@localhost:5432/dbname?sslmode=require`

## Model Download

The application uses IndicTrans2 for translation and XlitEngine for transliteration.

### Automatic Download

```bash
python scripts/download_indictrans2_model.py
```

This script:
1. Downloads the pre-converted CTranslate2 model from Hugging Face
2. Extracts vocabularies and tokenizers
3. Verifies model integrity
4. Saves to `models/indictrans2-ct2/`

### Manual Download

If the automatic script fails:

1. Download from Hugging Face Hub:
   ```bash
   huggingface-cli download adalat-ai/ct2-rotary-indictrans2-indic-en-dist-200M --repo-type model --local-dir models/indictrans2-ct2/
   ```

2. Verify model files:
   ```
   models/indictrans2-ct2/
   ├── model.bin
   ├── vocab/
   │   ├── model.SRC
   │   └── model.TGT
   └── ...
   ```

## Database Setup

### PostgreSQL Extensions

The application requires the `pgvector` extension for vector similarity search:

```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

### Database Tables

Tables are automatically created during migration:

- **occupations**: NCO occupation records with embeddings
- **prompt_history**: Search analytics and user queries
- **admin_settings**: Admin panel configuration
- **semantic_documents**: Indexed occupation documents

### Backup Database

#### Windows
```cmd
pg_dump -U postgres -d statathon_nco -F c -f backup.dump
pg_dump -U postgres -d statathon_nco > backup.sql
```

#### Linux/Ubuntu
```bash
sudo -u postgres pg_dump -d statathon_nco -F c -f backup.dump
sudo -u postgres pg_dump -d statathon_nco > backup.sql
```

### Restore Database

#### Windows
```cmd
pg_restore -U postgres -d statathon_nco backup.dump
psql -U postgres -d statathon_nco -f backup.sql
```

#### Linux/Ubuntu
```bash
sudo -u postgres pg_restore -d statathon_nco backup.dump
sudo -u postgres psql -d statathon_nco -f backup.sql
```

## Running the Application

### Development Mode

```bash
source venv/bin/activate  # Linux/Ubuntu
# or
venv\Scripts\activate     # Windows

python app.py
```

Access at: http://127.0.0.1:5000/

### Production Mode (Using Gunicorn)

Install Gunicorn:
```bash
pip install gunicorn
```

Run with 4 worker processes:

#### Linux/Ubuntu
```bash
gunicorn -w 4 -b 127.0.0.1:5000 app:app
```

#### Windows (using waitress instead)
```cmd
pip install waitress
python -m waitress --port=5000 app:app
```

### Behind a Reverse Proxy (Nginx)

Nginx configuration example:

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## Troubleshooting

### Common Issues and Solutions

#### 1. "ModuleNotFoundError: No module named 'flask'"

**Cause**: Virtual environment not activated

**Solution**:
- Windows: `venv\Scripts\activate`
- Linux/Ubuntu: `source venv/bin/activate`

Reinstall dependencies:
```bash
pip install -r requirements.txt
```

#### 2. "psycopg2.OperationalError: FATAL: password authentication failed"

**Cause**: Incorrect DATABASE_URL or PostgreSQL credentials

**Solution**:
1. Check `.env` file for correct credentials
2. Verify PostgreSQL is running:
   - Windows: Check Services → PostgreSQL
   - Linux/Ubuntu: `sudo systemctl status postgresql`
3. Test connection:
   ```bash
   psql -U postgres -d statathon_nco
   ```

#### 3. "ConnectionRefusedError: [Errno 111] Connection refused"

**Cause**: PostgreSQL server not running

**Solution**:
- Windows: Start PostgreSQL from Services or:
  ```cmd
  net start postgresql-x64-xx
  ```
- Linux/Ubuntu:
  ```bash
  sudo systemctl start postgresql
  ```

#### 4. "RuntimeError: Click will abort further execution because Python was called without the `-u` flag"

**Cause**: Buffered I/O issue

**Solution**:
```bash
python -u app.py  # Force unbuffered output
```

#### 5. "No module named 'ai4bharat.transliteration'"

**Cause**: Fairseq dependencies not installed

**Solution**:
```bash
pip install git+https://github.com/facebookresearch/fairseq.git@main
pip install "hydra-core==1.0.7" --no-deps
pip install bitarray
```

#### 6. Port 5000 Already in Use

**Cause**: Another application is using port 5000

**Solution**:
- Kill the existing process
- Or use a different port:
  ```bash
  python -c "from app import app; app.run(port=5001)"
  ```

#### 7. Slow Search Responses (~2-5 seconds)

**Cause**: Models still warming up or vector index not yet built

**Solution**:
- Wait 30-60 seconds after startup for model pre-warming
- For persistent slowness, check:
  ```bash
  psql -U postgres -d statathon_nco -c "\di"  # Check indexes
  ```

#### 8. "pgvector extension not available"

**Cause**: pgvector not installed in PostgreSQL

**Solution**:
```sql
-- Connect to your database
\c statathon_nco

-- Create extension
CREATE EXTENSION IF NOT EXISTS vector;

-- Verify
SELECT extname FROM pg_extension WHERE extname = 'vector';
```

#### 9. Models Download Fails

**Cause**: Network issues or insufficient disk space

**Solution**:
1. Check internet connection
2. Ensure 10GB+ free disk space
3. Manual download:
   ```bash
   huggingface-cli download adalat-ai/ct2-rotary-indictrans2-indic-en-dist-200M --repo-type model --local-dir models/indictrans2-ct2/
   ```

#### 10. "Translation takes too long (40+ seconds)"

**Cause**: Models are still initializing on first use

**Solution**:
- This is normal for the first search
- Subsequent searches will be much faster (~2-3 seconds)
- Models are pre-warmed at startup

## Performance Tuning

### For Production

1. **Increase Worker Processes**:
   ```bash
   gunicorn -w 8 -b 0.0.0.0:5000 app:app
   ```

2. **Enable Response Compression**:
   - Already enabled with Flask-Compress
   - Reduces JSON response size by 70%+

3. **Database Connection Pool**:
   - Default: 5 connections
   - For high traffic, increase in `db_store.py`:
     ```python
     pool = psycopg2.pool.SimpleConnectionPool(1, 20, ...)
     ```

4. **Cache Search Results**:
   - App caches identical queries automatically
   - TTL: 24 hours per cache entry

5. **PostgreSQL Tuning**:
   ```sql
   -- Increase work memory for vector operations
   ALTER SYSTEM SET work_mem = '256MB';
   ALTER SYSTEM SET maintenance_work_mem = '512MB';
   ALTER SYSTEM SET shared_buffers = '4GB';
   
   -- Apply changes
   SELECT pg_reload_conf();
   ```
